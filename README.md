# Uzma Fashion — Grand Opening

Link aplikasi: [uzma.web.id](https://uzma.web.id)

## Tentang Aplikasi

Website landing page untuk grand opening Uzma Fashion yang menampilkan cerita brand, koleksi fashion, promo pembukaan, hitung mundur acara, dan lokasi toko dengan desain responsif serta animasi scroll.

## Tech Stack

- SvelteKit 3 dan Svelte 5
- TypeScript
- Tailwind CSS 4
- GSAP (ScrollTrigger, ScrollSmoother, dan SplitText)
- Vite dan Bun
- Adapter Static untuk build situs statis
- Nginx dan Docker
- GitHub Actions, GitHub Container Registry (GHCR), dan Dokploy
